# Fence-estimator-v1-2

Fence Depot Estimator web app for quickly calculating linear footage, material cost, labor cost, tax, and grand total.

## Features

- Multiple fence types with different material rates
- Multiple gates with per-gate pricing
- Waste percentage control
- Labor model (per linear foot + per gate)
- Tax support
- Live currency formatting and totals
- Input validation with inline errors

## Run

1. Open `/home/runner/work/Fence-estimator-v1-2/Fence-estimator-v1-2/index.html` in a browser.
2. Enter project dimensions and pricing settings.
3. Click **Calculate Estimate**.
